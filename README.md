## What's inside

- `skills/` — reusable, composable skills for coding agents.
- More to come.

## Usage

Install all skills:

```bash
npx skills add leoxlin/skillets --skill '*'
```

Or pick individual ones:

```bash
npx skills add leoxlin/skillets --skill <skill-name>
```
